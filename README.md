# Documenta-o-de-Requisitos-Sistema-de-Agendamento-da-Barbearia-The-Family
Trabalho focado no levantamento de requisitos e modelagem de dados para um sistema de agendamento da Barbearia The Family. O objetivo é resolver a confusão de horários e cancelamentos de última hora do barbeiro Victor. Inclui DER, regras de negócio e dicionário de dados.
